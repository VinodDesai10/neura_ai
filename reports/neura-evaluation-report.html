2 Defect Found — isSmallTalk False Negative
One real classification error was discovered during testing. No production code was modified.
⚠ False Negative: isSmallTalk("how are you") → false

Expected: true  ·  Got: false  ·  Type: False Negative (FN=1)

The phrase "how are you" is explicitly listed in SMALL_TALK_WORDS in packages/shared/src/index.js. However, the isSmallTalk function applies a word-count guard (trimmed.split(/\s+/).length <= 2) before checking the phrase list. Since "how are you" is a 3-word phrase, the guard exits early and the phrase check is never reached.

Suggested fix: Check exact phrase membership in SMALL_TALK_WORDS before applying the word-count gate, or expand the gate to <= 3 words when the content is an exact phrase match.

4 Methodology

Each classifier was invoked with hand-labelled inputs grounded in the classifier's documented source logic. Binary classifiers report TP/TN/FP/FN plus precision, recall, and F1. The multi-class classifier (classifyMemoryType) reports a 3×3 confusion matrix plus one-vs-rest per-class metrics and macro-averages.

Test Case Design

Ground-truth labels were assigned by reading each classifier's source code logic (pattern-sets.js, shared/index.js, extractor.js, deduplicationService.js) and applying the same conditions a human reviewer would use. No randomisation was used.

Execution

All predictions are produced by calling the real production functions from @neura/core and @neura/shared. The test runner (tools/confusion-matrix.js) imports these packages via the npm workspace and invokes each function directly.

Metrics

Binary classifiers: TP, TN, FP, FN, accuracy, precision, recall, F1. Multiclass (classifyMemoryType): 3×3 confusion matrix, one-vs-rest per-class metrics, and macro-averaged scores.

No Production Changes

All test and reporting code lives in tools/ and reports/. No production modules were modified. The identified isSmallTalk defect is documented here for tracking — the fix is a separate concern.
